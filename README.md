# Student Focus Detection
AI-powered classroom monitoring system using computer vision and audio analysis.

## 📌 Features
- 👥 People detection
- 👀 Student focus detection
- 📱 Phone detection
- 🔊 Noise & audio monitoring
- 😊 Face & emotion analysis
- 🤖 AI classroom analysis
- 📷 Real-time camera monitoring

- OpenCV
- MediaPipe
- TensorFlow
- Flask
- HTML
- CSS
- JavaScript
